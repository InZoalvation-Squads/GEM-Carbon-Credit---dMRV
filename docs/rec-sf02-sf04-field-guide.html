Commissioning dateProject recordดึงจากวัน COD ของโปรเจ็กต์ (commission_date) อัตโนมัติ — แก้ที่หน้า Projects

Expected form of volume evidenceกรอกในระบบ — Section 3Metering data / Contract sales invoice / Other (ถ้า Other จะมีช่องระบุเพิ่ม)

§1.8 — Confirmation Signature · §1.9 — SF-02A · §1.11 — SF-02C

ช่องในฟอร์มแหล่งที่มาคำอธิบาย
§1.8 Signature / Name / Dateเซ็นบนกระดาษข้อความยอมรับ Privacy Policy เป็นข้อความคงที่ — ผู้มีอำนาจลงนามเซ็นหลังพิมพ์
SF-02A: Registrant's Declarationระบบคำนวณ + เซ็นบนกระดาษแสดงทุกครั้ง — ระบบเติมชื่อ Registrant (Organisation name) ลงในย่อหน้าคำประกาศให้ ช่อง Signature/Name/Date เซ็นมือ
SF-02B: Production Group Templateเว้นว่างในระบบไม่ render — ใช้เฉพาะการขึ้นทะเบียนแบบ Production Group ซึ่งอยู่นอกขอบเขตระบบ (โรงเดี่ยว)
SF-02C: Owner's Declarationระบบคำนวณ + เซ็นบนกระดาษแสดงเฉพาะเมื่อ Registrant ≠ Owner (§1.1 ตอบ No) — ระบบเติมชื่อ Registrant + Facility name ให้ ส่วน [วันที่/ชื่อเจ้าของ] ในวงเล็บเหลี่ยมกรอกมือบนหัวจดหมายเจ้าของ
เอกสารแนบ (อัปโหลดที่หน้า Evidence ไม่ใช่ในฟอร์ม): รูปถ่ายโครงการ · PPA · Meter Calibration Report (กรณีมิเตอร์ non-settlement) · Single Line Diagram · หลักฐานปริมาณไฟที่ผลิต · หลักฐานกำลังติดตั้ง (kW) · ใบอนุญาตผลิตไฟฟ้า (พค.2/ERC) · หลักฐานวัน COD · SF-02A ที่เซ็นแล้ว · SF-02C + หลักฐานความเป็นเจ้าของ (กรณีผู้ยื่นไม่ใช่เจ้าของ) · Declaration/Notice Letter (กรณีมี onsite consumer)

ส่วนที่ 2 — SF-04: Issue Request (v1.2.1)

เอกสาร 5 หน้า + หน้าปก/Document Control/Contents/Introduction · กรอกข้อมูลที่: หน้า REC Issuance → ปุ่ม New Issue Request (หรือปุ่ม "แก้ไข" บนแถว draft) · export ด้วยปุ่ม SF-04 บนทุกแถวของตาราง

§1.1 — SF-04: Issue Request

ช่องในฟอร์มแหล่งที่มาคำอธิบาย
Dateระบบคำนวณวันที่ submit คำขอ (submitted_at) — draft จะแสดงช่อง DD/MM/YYYY ว่าง
Request typeกรอกในระบบ — modal☑ Normal (ขายให้ผู้อื่น, ค่าธรรมเนียม 0.95 ฿/MWh) หรือ ☑ Self consumption (ใช้เอง, 1.33 ฿/MWh — อัตรา EGAT FN-01 2026)

§1.2 — Registrant and Facility Details

ช่องในฟอร์มแหล่งที่มาคำอธิบาย
Organisation ID/codeSnapshot จาก SF-02มาจาก "Organisation ID/code" (Section 2) ของ registration ที่ขึ้นทะเบียนแล้ว — freeze ณ ตอนสร้างคำขอ
Organisation nameSnapshot จาก SF-02มาจาก "Organisation name" (Section 2)
Facility ID/codeกรอกในระบบ — modal (ไม่บังคับ)รหัสโรงไฟฟ้าที่ Evident ออกให้หลัง SF-02 ผ่านการอนุมัติ — พิมพ์ครั้งเดียวในช่อง "Evident Facility ID/code" คำขอถัดไปของโปรเจ็กต์เดียวกันระบบ prefill ให้อัตโนมัติ
Facility nameSnapshot จาก SF-02มาจาก "Facility name" (Section 3)
Requested Labelsกรอกในระบบ — modal (ไม่บังคับ)Label ที่ขอให้ติดบนใบรับรอง — ใช้ได้เฉพาะ Label ที่บันทึกไว้กับ Facility registration บน Evident เท่านั้น เว้นว่างได้ถ้าไม่ใช้

§1.3 — Production Details

ช่องในฟอร์มแหล่งที่มาคำอธิบาย
Period start date / Period end dateกรอกในระบบ — modalช่วงเวลาการผลิตที่ขอออกใบรับรอง (เลือกจากช่วงที่มี monitoring records)
Total production during periodระบบคำนวณระบบรวม kWh จาก monitoring records ในช่วงที่เลือก ÷ 1000 = MWh (ทศนิยมสูงสุด 6 ตำแหน่ง) แสดงเป็นตารางตัวเลขทีละหลัก — ค่าถูก freeze ตอน submit
I-REC(E) applied forกรอกในระบบ — modal (ไม่บังคับ)จำนวน MWh ที่ขอออกจริง กรณีขอน้อยกว่ายอดผลิต — เว้นว่าง = ออกเต็มยอดผลิตข้างบน (ตามหมายเหตุในฟอร์ม)

§1.5 Production Auditor (ทั้งส่วน)เว้นว่างในระบบ + เซ็นบนกระดาษกรอกเฉพาะกรณีมี Production Auditor ภายนอกตรวจสอบคำขอ — Auditor เป็นผู้กรอกชื่อองค์กร + เซ็นเองบนเอกสารพิมพ์ (ระบบไม่มี workflow นี้)

§1.7 — SF-04A: Issuing Declaration · SF-04B/C

ช่องในฟอร์มแหล่งที่มาคำอธิบาย
SF-04A: Issuing Declarationเซ็นบนกระดาษแสดงทุกครั้ง — ข้อความคำประกาศเป็นข้อความคงที่ตามฟอร์มจริง ช่อง Signature / Name (BLOCK CAPITALS) / Date เซ็นมือโดยผู้มีอำนาจของ Registrant
SF-04B: Production Group Statementเว้นว่างในระบบไม่ render — ใช้เฉพาะ Production Group ซึ่งอยู่นอกขอบเขตระบบ
SF-04C: Fuel Consumption Statementเว้นว่างในระบบไม่ render — ใช้เฉพาะโรงไฟฟ้า multi-fuel (ระบบรองรับโซลาร์ fuel เดียว)
สรุปเส้นทางข้อมูล SF-04: ข้อมูลองค์กร/โรงไฟฟ้า/เชื้อเพลิง (§1.2, §1.4) ถูก snapshot มาจาก SF-02 registration ตอนสร้างคำขอ — ถ้าผิดต้องแก้ที่ registration · ช่วงเวลา + Facility ID + Labels + Receiving account กรอกใน modal (แก้ได้ตลอดขณะเป็น draft ด้วยปุ่ม "แก้ไข") · ยอด MWh ระบบคำนวณจาก monitoring records และ freeze ตอน submit · ลายเซ็นทั้งหมดเซ็นบนกระดาษหลังพิมพ์
