ทำอะไรไปบ้าง — 5 เรื่องหลัก

  • Export ฟอร์ม SF-04 ทางการ (Evident v1.2.1)คำขอออกใบรับรอง REC พิมพ์เป็นเอกสารตรงตามฟอร์มจริงได้จากทุกแถว
  • เพิ่มช่องข้อมูล Facility ID + Requested Labelsปิดช่องว่างข้อมูลใน SF-04 — พิมพ์ครั้งเดียว ระบบ prefill ให้ใบถัดไป
  • แก้ไขคำขอ (draft) ได้แล้วปุ่ม "แก้ไข" — เติมข้อมูลย้อนหลังได้ ไม่ต้องลบสร้างใหม่
  • ปรับปรุง UX หน้ากรอกฟอร์ม + แสดงสถานะ journeystep ที่กรอกครบเปลี่ยนเป็นสีเขียว ✓ และ REC Guide บอกว่า "คุณอยู่ขั้นนี้"
  • เอกสารคู่มือ Field Mapping (PDF ภาษาไทย)อธิบายทุกช่องของ SF-02/SF-04 ว่าค่ามาจากไหน ใครกรอก ตรงไหน

Export ฟอร์ม SF-04: Issue Request ทางการ

ตรงตามฟอร์มจริงทุกหน้า

สร้างเอกสาร Evident SF-04 v1.2.1 ครบทั้งชุด: หน้าปก, Document Control, Contents, Introduction, ฟอร์ม §1.1–1.6 และคำประกาศ SF-04A — ข้อความคงที่คัดลอกจาก PDF ต้นฉบับคำต่อคำ

เติมข้อมูลจากคำขอโดยอัตโนมัติ

วันที่ submit, ประเภทคำขอ (☑), ข้อมูลองค์กร/โรงไฟฟ้า, ช่วงเวลาผลิต, ยอด MWh แบบตารางตัวเลขทีละหลัก, บัญชีผู้รับใบรับรอง

ใช้งานง่าย

ปุ่ม "SF-04" อยู่บนทุกแถวของหน้า REC Issuance (ทุกสถานะ) — draft ก็ preview ได้ กด Print/PDF ได้ทันที

ครบทั้ง 2 ฟอร์มแล้ว

ตอนนี้ REC track มี export ทางการทั้ง SF-02 (ขึ้นทะเบียนโรงไฟฟ้า) และ SF-04 (ขอออกใบรับรอง) เทียบเท่า T-VER ที่มี PDD export

เรื่องที่ 2–3

เพิ่มข้อมูล SF-04 + แก้ไข Draft ได้

ช่องใหม่ 2 ช่อง

Evident Facility ID/code (รหัสที่ Evident ออกให้หลัง SF-02 ผ่าน) และ Requested Labels — เก็บลงฐานข้อมูลและแสดงใน SF-04 §1.2 ทั้งคู่เป็น optional ตามฟอร์มจริง

พิมพ์ครั้งเดียวพอ

คำขอใบถัดไปของโปรเจ็กต์เดียวกัน ระบบดึง Facility ID จากใบล่าสุดมาเติมให้อัตโนมัติ

ปุ่ม "แก้ไข" บนแถว draft

เปิดฟอร์มเดิมพร้อมข้อมูลที่เคยกรอก — เติม Receiving account, เปลี่ยนช่วงเวลา (ยอด MWh คำนวณใหม่ให้), แล้ว Save changes หรือ Save & Submit ได้เลย

ปิดปัญหาเดิม

เมื่อก่อน draft ที่ข้อมูลไม่ครบต้องลบทิ้งสร้างใหม่ — ตอนนี้แก้ตรงจุดได้ พร้อมแจ้งเตือนชัดเจนเมื่อบันทึกสำเร็จ/ล้มเหลว

ปรับปรุง UX — เห็นความคืบหน้าชัดขึ้น

Step chips อ่านรู้เรื่อง

หัวข้อขั้นตอนในหน้ากรอกฟอร์มแสดงชื่อ section จริง (เดิมเป็นแค่ตัวเลข 1. 2. 3.)

กรอกครบ = เขียว ✓

section ที่กรอกข้อมูลครบเปลี่ยนเป็นสีเขียวพร้อมเครื่องหมายถูก — เห็นทันทีว่าเหลืออะไร

REC Guide บอกตำแหน่งปัจจุบัน

ขั้นตอน ①–④ ที่ผ่านแล้วติ๊ก ✓ ขั้นที่กำลังอยู่มีป้าย "คุณอยู่ขั้นนี้" และเปิดหัวข้อนั้นให้อัตโนมัติ — คำนวณจากสถานะจริงของ registration ในระบบ
