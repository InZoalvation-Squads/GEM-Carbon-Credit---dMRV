สรุปผู้บริหาร (Executive Summary)

โครงการเดินหน้าตามแผนต่อเนื่อง โดยพัฒนาแล้วเสร็จ 4 เฟสหลัก ได้แก่ (1) ระบบหน้าบ้าน MVP ครอบคลุม workflow การขึ้นทะเบียนโครงการจนถึงการออกเครดิต (2) คลัง Methodology มาตรฐาน 8 รายการพร้อมสูตรคำนวณ (3) การยกระดับความปลอดภัยด้วยลายเซ็นดิจิทัลและ Verifiable Credentials ตามมาตรฐาน W3C และ (4) ระบบหลังบ้าน (Backend API) พร้อมฐานข้อมูลจริง ผ่านการทดสอบอัตโนมัติ 177 รายการ ขณะนี้อยู่ระหว่างเฟส 1b คือการเชื่อมหน้าบ้านเข้ากับหลังบ้านจริง

ความคืบหน้ารายเฟส

1. Sprint 1 – MVP ระบบขึ้นทะเบียนโครงการ (SPA)เสร็จสิ้น
ปลายมิถุนายน – ต้นกรกฎาคม 2026
  • ระบบล็อกอินและสลับบทบาทผู้ใช้ (Project Developer / VVB / Registry)
  • Registration Wizard สำหรับจัดทำเอกสาร PDD (Project Design Document) แบบอิง Methodology
  • Workflow การตรวจสอบของ VVB ครบวงจร: คิวงานตรวจ, อนุมัติ/ขอแก้ไข/ปฏิเสธ, บันทึก Audit Trail ทุกขั้นตอน
  • หน้าเอกสาร PDD แบบพิมพ์ได้ และระบบล็อกการใช้งาน dMRV จนกว่าโครงการจะขึ้นทะเบียนสำเร็จ
2. คลัง Methodology และสูตรคำนวณเสร็จสิ้น
ต้นกรกฎาคม 2026
  • รองรับ 8 Methodology: T-VER (โซลาร์, ลม, ชีวมวล, ไบโอแก๊ส, ป่าไม้ A/R, ก๊าซหลุมฝังกลบ), Verra VM0042/VM0047 และ CDM AR-ACM0003
  • ระบบคำนวณปริมาณการลดก๊าซเรือนกระจกแยกตามสูตรของแต่ละ Methodology โดยอัตโนมัติ
  • ออกแบบเป็น "Methodology-as-Data" — เพิ่ม Methodology ใหม่ได้ผ่านการ Import ไฟล์ JSON โดยไม่ต้องแก้โค้ด
3. Guardian Integration และ Phase 0 – Crypto Hardeningเสร็จสิ้น
10 – 22 กรกฎาคม 2026
  • จำลองการทำงานกับ Hedera Guardian: การ mint เครดิต VCU, Trust Chain ที่ตรวจสอบย้อนกลับได้ถึงเอกสาร PDD, การ anchor เอกสารด้วย IPFS CID และ HCS Topic รายโครงการ
  • เปลี่ยนจากการจำลองเป็นการเข้ารหัสจริง: SHA-256 กับไฟล์หลักฐานจริง, ตัวตนดิจิทัลแบบ did:key (Ed25519) ต่อบัญชีผู้ใช้
  • ออกเอกสารรับรองแบบ W3C Verifiable Credentials ที่ลงลายเซ็นดิจิทัล และตรวจสอบความถูกต้องได้แบบออฟไลน์ (ไม่ต้องพึ่งเซิร์ฟเวอร์)
  • Selective Disclosure — เปิดเผยเฉพาะข้อมูลที่จำเป็นต่อสาธารณะ ข้อมูลอ่อนไหวเก็บเป็นค่าแฮชที่พิสูจน์ได้ภายหลัง
  • จัดทำชุดเอกสาร Deployment Kit สำหรับติดตั้ง Guardian บนเซิร์ฟเวอร์ของบริษัท
4. Phase 1a – Backend API และฐานข้อมูลจริงเสร็จสิ้น
22 – 24 กรกฎาคม 2026
  • พัฒนา Backend ด้วย Fastify + Prisma เชื่อมต่อฐานข้อมูล PostgreSQL ของบริษัท
  • ระบบยืนยันตัวตนด้วย JWT + Argon2 พร้อม Refresh Token Rotation ตามแนวปฏิบัติด้านความปลอดภัย
  • Audit Chain แบบต่อเนื่อง (tamper-evident) ครอบคลุมทุกการเปลี่ยนแปลงข้อมูล พร้อม API ตรวจสอบความสมบูรณ์ของสายโซ่
  • ระบบอัปโหลดหลักฐานพร้อมคำนวณ SHA-256 ฝั่งเซิร์ฟเวอร์แบบสตรีม, API จัดการโครงการ / ค่า Emission Factor / ข้อมูล Monitoring
  • Workflow ขึ้นทะเบียน PDD และการทวนสอบ (Verification) ครบวงจรผ่าน API พร้อมการ anchor เอกสารรับรองที่ตรวจลายเซ็นฝั่งเซิร์ฟเวอร์
  • ผ่านการทดสอบอัตโนมัติ 177 รายการ และผ่านการ Code Review ทุกโมดูล
5. Phase 1b – เชื่อมหน้าบ้านเข้ากับ Backend จริง (Cutover)กำลังดำเนินการ
24 กรกฎาคม 2026 – ปัจจุบัน
  • จัดทำแผน Cutover และพัฒนา API Client ฝั่งหน้าบ้านแล้ว — ระบบล็อกอินสลับไปใช้ Backend จริงได้ผ่านการตั้งค่า (เปิด/ปิดได้อย่างปลอดภัย)
  • กำลังปรับปรุงส่วน UI (Sidebar / TopBar) พร้อมเพิ่มการทดสอบ UI
  • จัดทำรายงาน Workflow ป่าไม้ฉบับภาษาไทยประกอบการนำเสนอ
